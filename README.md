# Plataforma Web Gamificada de Matemáticas

Proyecto de estadías enfocado en el desarrollo de un sistema web para apoyar el aprendizaje de matemáticas mediante mecánicas de juego (puntos, niveles y tablas de clasificación).

## Stack Tecnológico
- **Frontend:** Ionic / React
- **Backend:** Node.js / PHP
- **Base de Datos:** MySQL

## Estructura del Repositorio
- `docs/`: Documentación del proyecto, análisis y casos de uso.
- `database/`: Diagrama entidad-relación y scripts de la base de datos.
- `src/`: Código fuente del sistema.

## Estado del Proyecto
Actualmente en la fase inicial de análisis, modelado de base de datos y diseño de arquitectura.
