# Plataforma Web Gamificada de Matemáticas

Proyecto de estadías enfocado en el desarrollo de una aplicación web para apoyar el aprendizaje de matemáticas mediante mecánicas de juego (puntos, niveles y tablas de clasificación).

## Stack Tecnológico
- **Frontend:** Ionic / React (HTML, CSS, JavaScript)
- **Backend:** PHP
- **Base de Datos:** MySQL

## Estructura del Repositorio
- `docs/`: Documentación del proyecto, análisis y casos de uso.
- `database/`: Diagrama entidad-relación y scripts SQL.
- `src/`: Código fuente del sistema.

## Estado del Proyecto
Fase inicial de análisis de requerimientos, modelado de base de datos y arquitectura.
